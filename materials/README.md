# Materials Directory

Place your custom materials (.vmt and .vtf files) here.

## Structure
```
materials/
  └── models/          # Model textures
      └── yourmodel/   # Organize by model
  └── vgui/           # HUD/UI materials
  └── effects/        # Effect materials
```

## Notes
- Materials must be in .vtf format (textures)
- Materials need .vmt files (material definitions)
- Use VTFEdit to convert images to .vtf
