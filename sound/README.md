# Sound Directory

Place your custom sound files here.

## Structure
```
sound/
  └── custom/          # Your custom sounds
      └── weapons/     # Weapon sounds
      └── ambient/     # Ambient sounds
      └── music/       # Music files
```

## Notes
- Supported formats: .wav, .mp3 (but .wav is preferred)
- Keep file sizes reasonable
- Use mono for 3D positional sounds
- Use stereo for music/UI sounds
